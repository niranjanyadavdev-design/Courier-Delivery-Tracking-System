# 🚚 Courier Delivery Tracking System

## 📌 Project Description
The Courier Delivery Tracking System is a console-based Java application developed using Object-Oriented Programming (OOP) concepts. This system helps users manage and track courier parcels efficiently using a unique parcel ID. It provides a simple and user-friendly interface to perform operations like adding parcels, updating status, and tracking delivery details.

---

## 🎯 Features
- Add new parcel  
- Update parcel status (Dispatched, In Transit, Delivered)  
- Track parcel details  
- View delivery timeline with date & time  
- Display all parcels  

---

## 🛠️ Technologies Used
- Java (Core Java)  
- Object-Oriented Programming (OOP)  
- ArrayList for dynamic data storage  
- Java Date & Time API  

---

## 📂 Project Structure
- Main.java (Main class)  
- Parcel class  
- Methods:
  - addParcel()  
  - updateParcel()  
  - trackParcel()  
  - showAllParcels()  

---

## ▶️ How to Run
1. Install Java (JDK 8 or above)  
2. Open the project in any IDE (VS Code / Eclipse / IntelliJ)  
3. Compile the code using:
   javac Main.java  
4. Run the program:
   java Main
